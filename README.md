# Практическая работа №1 
## Цель 
- Узнать информацию о компьюетере с помощью терминала и кода. 
## 1. Информация о компьютере 
(MachineName, UserName, дата и время)
## 2. Информация об операционной системе 
(OSVersion, Is64BitOperatingSystem, сравнение с Параметрами Windows) 
## 3. Логические процессоры 
(гипотеза, результат программы, результат Диспетчера задач, совпадают ли) 
## 4. Память процесса 
(результат WorkingSet, сравнение с Диспетчером задач) 
## Контрольные вопросы 
1. Потому что операционная система хранит имя компьютера.
2. Управление ресурсами и предоставление программам информацию о системе.
3. ОС рассчитанная на работу с 64-битной архитектурой.
4. Показывает логичесские процессы, может не совпадать, потому что на ядре может быть поддержка нескольких потоков.
5. WorkingSet показывает объём физической оперативной памяти, используемой конкретным процессом в данный момент. Вся оперативная память включает ресурсы, используемые всеми программами и системой.
6. Потому что компьютеры могут иметь разные процессоры, объём оперативной памяти, операционные системы, имена устройств и настройки.

## Дополнительное задание. Мини-монитор системы 
### Что делает программа 
Считывает обьем потребляемой памяти в разное время.
### Что нового я узнал о классе Process 
Что он получает обьект , который представляет процесс программы.
### Сравнение памяти программы и Диспетчера задач 
Память постоянно меняется если брать "Диспетчер задач", а если брать WorkingSet он показывает потребление памяти конкретного процесса.
### Почему значение памяти может немного изменяться 
Потому что в разное время может быть наложено больше задачь на программу. Из-за этого нагрузка на процессор в разное время не может быть одинаковым.
